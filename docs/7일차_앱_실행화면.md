# 7일차 앱 실행 화면

## 1. 회원가입

- **Endpoint:** `POST /api/v1/auth/signup`
- **동작:** 사용자가 회원가입 정보를 입력하고 가입을 요청한다.

![회원가입](images/1_회원가입.png)

## 2. 로그인

- **Endpoint:** `POST /api/v1/auth/login`
- **동작:** 로그인 후 인증된 사용자로 서비스를 이용한다.

![로그인](images/2_로그인.png)

## 3. 토큰 갱신

- **Endpoint:** `POST /api/v1/auth/refresh`
- **동작:** Refresh Token을 이용해 Access Token을 갱신한다.

![토큰 갱신](images/3_인증_토큰갱신.png)

## 4. 로그아웃

- **Endpoint:** `POST /api/v1/auth/logout`
- **동작:** 로그아웃하여 인증 세션을 종료한다.

![로그아웃](images/4_로그아웃.png)

## 5. 마이페이지 조회

- **Endpoint:** `GET /api/v1/users/me`
- **동작:** 로그인한 사용자의 정보를 조회한다.

![마이페이지 조회](images/5_마이페이지_내정보조회.png)

## 6. 마이페이지 정보 수정

- **Endpoint:** `PATCH /api/v1/users/me`
- **동작:** 로그인한 사용자의 정보를 수정한다.

![마이페이지 정보 수정](images/6_마이페이지_내정보수정.png)

## 7. 비밀번호 변경

- **Endpoint:** `PATCH /api/v1/users/me/password`
- **동작:** 로그인한 사용자의 비밀번호를 변경한다.

![비밀번호 변경](images/7_마이페이지_비밀번호변경.png)

## 8. 회원 탈퇴

- **Endpoint:** `DELETE /api/v1/users/me`
- **동작:** 로그인한 사용자가 회원 탈퇴를 요청한다.

![회원 탈퇴](images/8_마이페이지_회원탈퇴.png)

## 9. 회원 목록 조회

- **Endpoint:** `GET /api/v1/users`
