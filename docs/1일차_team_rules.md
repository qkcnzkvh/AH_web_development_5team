# 🐙 부담 제로! Git & GitHub 약속

## 1. 🌳 나만의 공간에서 작업하기 (Branch)

메인 공간(`main`/`dev`)은 모두의 공통 공간이니까, 안전하게 나만의 작업 공간(`feature/이름-기능`)을 만들어서 자유롭게 요리조리 시도해 봐요!

## 2. ✉️ 친절하고 알기 쉬운 메시지 (Commit)

내가 뭘 했는지 팀원들이 한눈에 알아볼 수 있도록 짧고 알기 쉽게 적어주기만 하면 돼요.

예시:
- `feat: 로그인 화면 완성했어요!`
- `fix: 버튼 위치 살짝 바꿨어요`

## 3. 🔀 서로 응원하는 코드 리뷰 (PR)

작업이 끝나면 "PR 올려두었어요!" 하고 가볍게 공유해 주세요. 팀원들의 코드를 보면 "우와 이 부분 멋져요!", "고생 많으셨어요!" 같은 따뜻한 칭찬과 응원의 한마디를 남겨주세요 💌

## 4. 🏡 서로의 평온한 교육, 팀 프로젝트 수료를 위해서 아낌없이 기여도를 나눠줘요 😉
